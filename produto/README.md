# 🚀 Artefato Final do Produto — CTBJ Conecta

O **CTBJ Conecta** é uma plataforma web desenvolvida para otimizar o agendamento, gestão e reserva de espaços físicos e recursos didáticos do Colégio Técnico de Bom Jesus (CTBJ/UFPI).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & JavaScript (ES6+)**: Estrutura e lógica do sistema em arquivo único.
- **Tailwind CSS**: Estilização moderna e responsiva.
- **LocalStorage API**: Persistência de dados das solicitações diretamente no navegador.

---

## 🖥️ Como Executar o Projeto

1. Faça o download ou clone este repositório.
2. Navegue até a pasta `produto/`.
3. Abra o arquivo `index.html` em qualquer navegador web (Google Chrome, Firefox, Edge).

---

## ✨ Principais Funcionalidades

- **Autenticação Multi-perfil**: Módulos específicos para *Aluno*, *Professor*, *Coordenador* e *Diretor*.
- **Filtro por Categoria**: Visualização rápida de laboratórios de Informática, Agropecuária, Enfermagem e Auditório.
- **Validação de Conflitos**: Bloqueio automático de agendamentos duplicados no mesmo ambiente e horário.
- **Painel de Gestão**: Controle de aprovação e rejeição de solicitações em tempo real.
